## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/EmberRift.git`
2. `cd EmberRift`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure EmberRift, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
